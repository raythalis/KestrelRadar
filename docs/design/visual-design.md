# 视觉设计

本文描述当前产品使用的设计语言，不记录旧阶段的测试计数或预览样例清单。精确取值以 `apps/web/src/design/v2/tokens.ts` 为准，页面样式在 `apps/web/src/styles/v2.scss`；不要在多个文档复制一整套 token 数值。

## 层次与职责

Foundation token → Vuetify 主题与 CSS 变量 → App/业务组件 → 正式页面。颜色、排版、间距、圆角、阴影、密度、图标尺寸和动效由同一份 V2 token 定义并生成 `--k2-*`；Vuetify 主题色也由它派生。旧 `--k-*` 名称只用于兼容既有组件，不是第二套配色源。组件消费语义变量，页面负责用户任务、数据和布局；不要把组件演示页结构照搬到正式页面。

## 视觉语言

- 亮/暗两套主题共享语义角色；背景、卡片表面、文字和描边逐层区分。品牌主色用于主要操作与强调；成功、警告、危险和信息色用于对应语义，不靠颜色单独传达状态。
- 小字号文字优先使用柔和底与较深的文字色，保持对比度。选中文本、状态短标签及图标容器分别承担信息层级，避免同一状态同时叠多种强调。
- 排版使用已有字阶和字重，中文走系统字体回落；技术串才使用等宽字体。字体与图标资源说明见[字体](fonts.md)。
- 页面与卡片使用 token 给出的间距和密度；组件特有的尺寸留在组件内，不为了一个页面额外增加全局 token。危险操作和普通操作应有清晰层级。
- 主题可在亮色、暗色、跟随系统之间切换；目前没有用户可选的主色板。切换亮暗时，弹窗等浮层也使用同一主题。

## 页面布局与响应式

外壳的侧栏和导航由 `AppShell` 管，业务页使用 `.k2-page` 系列。**当前代码**中的默认宽度档为 1120px，宽页档 1440px；实际产品五个主页面都使用宽页档，配合容器自身的内边距。窄屏两栏活动区在 `max-width: 1183px` 时改为单列；具体断点以使用处的样式规则为准，不把 token 中的通用断点误当作所有组件的统一收缩点。页面结构先按任务决定，见[正式页面](product-pages.md)。

## 对照与验证

开发环境的 `/style-lab` 可查看 token 与组件状态，但不在生产构建中。变更视觉规则时，除组件自身外还需核对正式页面和亮暗主题；遵循[界面文案](ux-writing.md)的自解释原则。旧阶段的数字与样例记录留在本地工作资料，不作为当前规范正本。
