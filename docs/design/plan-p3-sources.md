## 由此确定的 SourceCard 结构

- 头：图标 + 名称 + 类型；右上角 ×。
- 身：状态块（＝抓取测试入口，颜色分 有内容 / 抓得到但没内容 / 抓取失败 / 抓取测试 / 抓取中 / 已停用）+ 路由或地址（等宽）。
- 脚：采集频率（左）+ 启用开关（右）。
- 抓取中：状态块转圈且不可点；停用的源不给抓（`disabled`）。
