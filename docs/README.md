# Kestrel Radar 文档

Kestrel Radar 是自托管的信息监听与事件响应应用。按你要做的事选择入口：

- [快速开始](getting-started.md)：从安装、首次启动到建立第一组发现、监听与动作。
- [使用手册](usage.md)：配置分组、发现、监听、动作，查看事件与异常，判断为什么没通知。
- [配置](configuration.md)：环境变量、界面设置、渠道、模型、数据和备份。
- [HTTP API](api.md)：端点、请求结果与错误响应，供集成开发使用。
- [判定与打分](judgment-scoring.md)：关键词、分数、灵敏度和判定结论。
- [LLM+](llm-plus.md)：何时调用模型、失败处理与可能产生的费用。
- [部署](deployment.md)：Docker、启动脚本、手动运行、反向代理、升级。
- [设计规范](design/README.md)：当前有效的界面与文案规则，供贡献者使用。

安装或运行遇到问题，先看[部署](deployment.md)的安全与数据说明及[使用手册](usage.md)的“不产生事件/不投递”排查。尚无经核实的独立故障排查篇，因此暂不建立 `troubleshooting.md`。
