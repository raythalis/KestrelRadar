# Kestrel Radar documentation

Kestrel Radar is a self-hosted information monitoring and event response app. Choose a guide based on your task:

- [Getting started](getting-started.en.md): install and start Kestrel Radar, then set up your first discovery, monitor, and action.
- [User guide](usage.en.md): configure groups, discoveries, monitors, and actions; inspect events and incidents; investigate missing notifications.
- [Configuration](configuration.en.md): environment variables, interface settings, channels, models, data, and backups.
- [HTTP API](api.en.md): endpoints, operation results, and error responses for integration developers.
- [Judgment and scoring](judgment-scoring.en.md): keywords, scores, sensitivity, and judging outcomes.
- [LLM+](llm-plus.en.md): when a model is called, failure handling, and potential costs.
- [Deployment](deployment.en.md): Docker, start scripts, manual operation, reverse proxies, and upgrades.
- [Design guidance](design/README.en.md): current interface and writing rules for contributors, including [foundations](design/foundation.en.md), [visual design](design/visual-design.en.md), [typography](design/fonts.en.md), [product pages](design/product-pages.en.md), and [UX writing](design/ux-writing.en.md).

For installation or runtime problems, start with the security and data sections of [Deployment](deployment.en.md) and the “no events/no deliveries” troubleshooting in the [User guide](usage.en.md). There is no independently verified troubleshooting guide yet, so there is no `troubleshooting.md`.
